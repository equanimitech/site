A principle of the [Equanimity layer](/notes/start-here). The asymmetry is the whole point. The tool should teach something the user comes to carry on their own, and so needs the tool less. A graduated user is a success, not a churn metric.

**The design test**

> If a user stopped after six months because they had internalized the skill, would we celebrate or panic?

<details>
<summary>How it shows up in the work</summary>

- **Zenborg**: attitude and rhythm awareness build the user's own capacity to tend their garden. Eventually the tool is a mirror reflecting patterns the user already knows, not a prompt telling them what to do.
- **keel**: nudges fire once, then go quiet. Success is the tool disappearing. The friction dial easing to nothing, because your own rhythm holds, is the tool fading on purpose.
- **Respost**: two postcards a month is a success. No streaks.

The engagement world's tools panic when you leave. These are built to be left.

</details>
